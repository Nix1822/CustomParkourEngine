# Custom Parkour Engine & Timer System

Parkour plugin for Paper 1.21.4 (Java 21). Times are saved in SQLite

## Commands

    /parkour create <name>
    /parkour setstart <name>
    /parkour addcheckpoint <name> <number>
    /parkour leaderboard <name>

Stand on a pressure plate when you run setstart or addcheckpoint. The highest checkpoint number is the finish
